# Habit Fix Wellness

> Build Better Habits. Feel Better. Live Better.

Habit Fix Wellness by Coach Raju Raut — Personalized wellness guidance, healthy habits, nutrition awareness, hydration tracking, BMI calculator, and lifestyle coaching.

## 🚀 Features

- **Personalized Coaching & Habit Support**: Sustainable strategies for sustainable health.
- **Interactive Tools**:
  - Built-in BMI Calculator & Health Category Assessment
  - Wellness Self-Assessment Quiz
  - Habit & Lifestyle Trackers
- **Responsive Modern Design**: Built with semantic HTML5, modern CSS3 styling, and vanilla JavaScript.
- **Consultation & Booking Flow**: Direct consultation scheduling and habit program onboarding.

## 🛠️ Getting Started

Open `index.html` in any modern web browser or serve via a local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve .
```
